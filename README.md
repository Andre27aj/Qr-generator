# QR Generator

**Live site:** [qrcode.ajoaquim.com](https://qrcode.ajoaquim.com)

A clean, minimal QR code generator that runs entirely in the browser — no server, no build tools, no dependencies to install.

## Features

- 6 QR types: URL, Text, Email, Wi-Fi, vCard, Phone
- Live preview as you type
- Custom foreground & background colors
- Download as PNG

## Usage

Open `index.html` in any browser. No setup required.

## Deploy

Hosted on Cloudflare Pages — every push to `main` triggers an automatic redeploy.
